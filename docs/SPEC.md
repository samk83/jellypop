# SPEC: 젤리팝 v0.1 — 시안 겸 플레이 가능한 웹 버전

> 마지막 수정: 2026-10-20
> Owner 요청: "단순게임이니깐 시안부터 해줘, 웹기반으로 플레이할 수 있게, 핸드폰도"
> 장르 선택(Claude 기본값): 같은 색 젤리 묶음을 터치해 터뜨리는 퍼즐(콜랩스형). 스와이프 없이 터치 한 번이라 휴대폰에 맞음.

## 1. 목표
휴대폰·PC 브라우저에서 설치 없이 바로 하는 젤리 터뜨리기 퍼즐. 화면 디자인(시안)을 실제로 플레이하며 확인할 수 있게 한다.

## 2. 범위
| 만들 것 | 안 만들 것 (이번 범위 밖) |
|---|---|
| 시작 화면 / 게임 화면 / 결과 화면 | 로그인, 순위표, 서버 |
| 같은 색 2개 이상 터치로 터뜨리기, 중력으로 채우기 | 결제, 광고 |
| 7개 이상 → 폭탄 젤리(3x3, 연쇄) | 스테이지 지도, 장애물 블록 |
| 레벨(목표 점수·터치 횟수), 별 1~3개 | 앱스토어용 앱 포장 |
| 효과음(끄기 가능), 진동, 최고 기록(브라우저 저장) | 배포(L3, 승인 후) |

## 3. 수락기준
| # | 수락기준 | 확인 방법 | 상태 |
|---|---|---|---|
| 1 | 시작 화면에서 "플레이"를 누르면 레벨 1이 남은 터치 20으로 시작한다 | 자동 테스트 | ✅ |
| 2 | 붙어 있는 같은 색 젤리 2개 이상을 터치하면 한꺼번에 터지고, 점수(10×n×(n-1))가 오르고, 남은 터치가 1 줄어든다 | 자동 테스트(터치) | ✅ |
| 3 | 외톨이 젤리를 터치하면 흔들리기만 하고 터치 횟수는 줄지 않는다 | 자동 테스트 | ✅ |
| 4 | 터진 자리는 위 젤리가 떨어지고 새 젤리가 채워져 빈칸이 남지 않는다 | 자동 테스트 | ✅ |
| 5 | 7개 이상 터뜨리면 폭탄 젤리가 생기고, 폭탄은 3x3을 터뜨리며 옆 폭탄도 연쇄로 터진다 | 자동 테스트(규칙) | ✅ |
| 6 | 목표 점수를 넘기면 클리어 화면(별, 남은 터치 보너스, 다음 레벨), 터치를 다 쓰면 실패 화면(다시 도전)이 나온다 | 자동 테스트(클리어·실패 모두) | ✅ |

| 8 | 움직일 묶음이 없으면 자동으로 섞는다 | 자동 테스트 | ✅ |
| 9 | 키보드(방향키+Enter)로도 플레이할 수 있다 | 자동 테스트 | ✅ |

## 4. 리스크
| 리스크 | 대응 |
|---|---|
| 난이도가 너무 쉽거나 어려움 | 자동 테스트에 단순 전략 50판 시뮬레이션(레벨별 클리어율) 포함, 숫자는 `Logic.levelConfig`에서 조정 |
