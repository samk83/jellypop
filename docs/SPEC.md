# SPEC: 젤리팝 v0.2 — 젤리마을 대소동 · 월드 1 (버블 슈터)

> 마지막 수정: 2026-10-20
> 근거: 스토리보드 v0.2 (`design/storyboard/`), Owner 지시 "계속진행해" (추천안: 코드 그림 먼저, 월드 1 먼저)
> 이전 버전(톡 터뜨리기)은 `classic.html`, SPEC은 `docs/SPEC-v0.1.md`에 보관.

## 1. 목표
휴대폰·PC 브라우저에서 바로 하는 버블 슈터. 말랑이가 핸들을 돌려 대포를 움직이고, 줄 선 친구들을 쏘아 갇힌 친구를 구한다. 월드 1(6스테이지)을 끝까지 플레이할 수 있게 만든다.

## 2. 범위
| 만들 것 | 안 만들 것 (이번 범위 밖) |
|---|---|
| 타이틀, 프롤로그(4컷), 모험 지도, 플레이, 결과, 스티커 북 | 월드 2~5 (24스테이지), 엔딩 |
| 끌어서 조준(핸들 돌리는 말랑이) → 떼면 발사, 벽 튕김 | 하트(도전 횟수) 제한, 결제, 광고 |
| 같은 색 3개 이상 펑, 매달린 데 없는 거품 떨어짐 | 3D 고급 그림 (나중에 이미지로 교체) |
| 줄 선 친구들 = 남은 발사 수, 맨 앞 친구 눌러 순서 바꾸기 | 서버·순위표 |
| 친구 거품 구출, 스테이지 6개(각 테마 배경), 보스 뭉치 | 배포(L3, 승인 후) |
| 클리어마다 친구 스티커·별, 지도에서 말랑이 한 칸 이동, 저장 | |
