# 젤리팝 스토리 — 30스테이지 이야기

> 스테이지를 **처음** 깰 때마다 결과 창의 "다음 스테이지로"를 누르면 짧은 애니메이션 컷신이 나온다. 원본 데이터: `story-data.js`

## 큰 줄기

노놈이 마을 젤리들을 거품에 가둬 데려간다 → 말랑이가 한 명씩 구하며 쫓아간다 → 보스 4명(뭉치·찐득이·푸딩 골렘·철컹이)이 하나씩 떨어뜨린 종이 조각을 모으면 **노놈의 생일 초대장** → 초대장이 바람에 날아가 아무도 오지 않았던 노놈의 외로움이 밝혀진다 → 30스테이지에서 노놈을 이긴 뒤 **다 함께 생일 파티**.
